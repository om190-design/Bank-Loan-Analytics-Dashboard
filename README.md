# Bank Loan Analytics Dashboard Using Power BI

This project analyzes bank loan applications and portfolio performance using Microsoft Power BI.

 Key KPIs
- Total Loan Applications: 38,576
- Total Funded Amount: 436M
- Total Amount Received: 473M
- Average Interest Rate: 12.05%
- Average DTI Ratio: 13.33%
- Good Loans: 86.18% | Bad Loans: 13.82%\
